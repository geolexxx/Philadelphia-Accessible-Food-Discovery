# 工程验证记录

日期：2026-09-20。验证对象：本地 Fieldfare 原型。以下是工程检查，不是目标用户研究或线上业务结果。

## 自动化

执行 `python3 scripts/build_data.py --source <原项目目录>` 成功；再次重建仍得到 1,798 条 POI、408 个区域、9 对待核验关联。输入哈希见 manifest。

执行 `npm test`：11 项通过、0 失败。覆盖：

- 球面距离单位、对称性及零距离。
- Polygon / MultiPolygon、区域内环排除。
- 堆排序；Dijkstra 多边最短路径；不可达节点。
- 正向/反向单行道及双向街道。
- 模型时间公式；预算和无效路线过滤。
- Nearby 与 drive 分离；SNAP unknown 不混同 historical。
- 搜索、区域、类别、收藏及排序组合。
- 快照数量、唯一源 ID、来源关联、完整度及区域 ID 一致性。
- 真实路网节点引用合法；City Hall 在 150 m 内有连接点；可到达超过 1,000 个路网节点；抽查路径不短于端点直线距离。

执行 `npm run check`：三个 JavaScript 模块语法检查通过。
